### Umlinganiswa

--- task ---

Yenza🐙👩‍🦼🦖 **owona mlinganiswa** ubonise umdla kuloo nto. Yongeza iibhloko ekugqibeleni kwe skripthisokuseta so 🐙👩‍🦼🦖 **mlinganiswa oyintloko**.

Ukuba ufuna 🐙👩‍🦼🦖 **umlinganiswa oyintloko** ulinda de i-🎂🎾🎁 **into enomdla** yenze into ethile, yongeza ibhloko `linda`{:class="block3control"}.

![Imvelaphi yasentlango enelitye elishukuma ngapha nangapha.](images/bear.gif)

Ungasebenzisa iibhloko `yithi`{:class="block3looks"} okanye `cinga`{:class="block3looks"}, okanye usebenzise ulwandiso lwo `Mbhalo ojikwa abe yiNtetho`{:class="block3extensions"} ukwenza umlinganiswa athethe ngokuvakalayo!

[[[scratch3-text-to-speech]]]

Umlinganiswa angabonakalisa iimvakalelo, njengakwiprojekthi ethi [Incoko yesithuba](https://projects.raspberrypi.org/en/projects/space-talk){:target="_blank"}.

[[[scratch3-change-costumes-to-show-mood]]]

Umlinganiswa unokuba nesibindi aze asondele ngakumbi ukuze ajonge into leyo.

**Uvavanyo:** Cofa kwiflegi eluhlaza ukuze uvavanye iprojekthi yakho. U-🐙👩‍🦼🦖 **mlinganiswa oyintloko** kufuneka abonise umdla malunga nento leyo.

Cofa kwiflegi eluhlaza kwakhona. Ukuba utshintshe indawo okanye inkangeleko ye-🎂🎾🎁 **into enomdla** okanye 🐙👩‍🦼🦖 **umlinganiswa oyintloko** isprite, kuya kufuneka uqinisekise ukuba zibuyele kwindawo yazo yokuqala okanye inkangeleko xa uqala iprojekthi kwakhona.

title: Misela indawo yokuqala kunye ne nkangeleko ye sprite
---

Khetha iibhloko ozidingayo ukuze umisele indawo kunye nenkangeleko ye sprite ekuqaleni.

```blocks3
when flag clicked // yongeza iibhloko ukuseta isiqalo
switch costume to [ikhostyum 1 v]
set size to (100) % // ubungakanani bokuqala
go to x: (-200) y: (50) // indawo yokuqala
point in direction [90]
set [ukuqaqamba v] effect to [80]
show
```

**Icebiso:** Zonke iziphumo zemizobo ziyasuka xa ucofe kwiflegi eluhlaza, ngoko ke akukho sidingo soba uzisuse, kodwa kunokufuneka usete iziphumo ofuna ukuba i-sprite sibe nazo.
